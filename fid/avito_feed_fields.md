## Детали по полям

### Уникальный идентификатор объявления
- **Источник:** `GET /core/v1/items/{id}` → `uniqueId`
- Стабильный ID, не меняется при переопубликовании
- Используется Avito AutoLoad для сопоставления записей

### Способ размещения
- Пример: `Package`
- Выпадающий список

### Номер телефона
- Формат: `79398997136` (без пробелов, начинается с 7)

### Способ связи
- Пример: `По телефону и в сообщениях`
- Выпадающий список

### Ссылки на фото
- Формат: URL через разделитель `|`
- Получаются из `/images/v1/items/{id}/images`

### Тип детали двигателя / TypeID
- Параметр категории "Для автомобилей-Двигатель"
- Выпадающий список из листа "Спр-Для автомобилей-Двигатель"

### AvitoDateEnd
- Формат: `dd.MM_YYYY`
- Пример из образца: `13.07_176`

### AvitoStatus
- Значения: `active`, `removed`, `old`, `blocked`, `rejected`

## Структура категории

```
Транспорт - Запчасти и аксессуары - Запчасти - Для автомобилей - Двигатель
```
