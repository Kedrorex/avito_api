# План реорганизации проекта Avito Republisher

## Текущее состояние

Проект содержит:
- ~30 PHP файлов в корне (тесты, дебаг-скрипты, утилиты)
- 4 .db файла в `data/` (только один используется)
- Нет структуры для тестов и CLI-утилит

## Цель

Привести проект в порядок:
1. Создать папку `tests/` для всех тестовых файлов
2. Создать папку `scripts/` для диагностических/утилитарных скриптов
3. Оставить в корне только production-файлы
4. Очистить `data/` — оставить только `avito.db`, бэкапы перенести в `data/backups/`
5. Обновить `.gitignore`
6. Обновить пути в файлах (require/include)

## Детальный план

### 1. Создать папки

```
tests/          — тестовые скрипты
scripts/        — диагностические и утилитарные скрипты
data/backups/   — бэкапы БД
```

### 2. Переместить тестовые файлы в `tests/`

| Файл | Описание |
|------|----------|
| `test_item.php` | Тестирование статистики 10 объявлений |
| `test_all_pages.php` | Тест всех страниц |
| `test_item_stats.php` | Тест статистики элемента |
| `test_repository.php` | Тест репозитория |
| `test_stats.php` | Тест статистики |
| `test_integration.php` | Интеграционный тест |
| `test_env.php` | Тест окружения |

### 3. Переместить `collect_1000_stats.php` в `bin/`
- `collect_1000_stats.php` → `bin/collect_1000_stats.php` (production CLI-скрипт)

### 4. Переместить диагностические скрипты в `scripts/`

| Файл | Описание |
|------|----------|
| `check_db.php` | Проверка БД |
| `check_item.php` | Проверка элемента |
| `check_item_date.php` | Проверка даты элемента |
| `get_stats.php` | Получение статистики |
| `count_active.php` | Подсчёт активных объявлений |
| `debug_api.php` | Дебаг API |
| `debug_endpoint.php` | Дебаг эндпоинта |
| `debug_pagination.php` | Дебаг пагинации |

### 5. Очистить `data/`

**Оставить:**
- `data/avito.db` — основная БД (используется в `config/avito.php`)

**Переместить в `data/backups/`:**
- `avito.backup.before_full.db`
- `avito.backup.before_1000.db`

**Удалить (не используется):**
- `avito_test_temp.db` — временный тестовый файл

### 6. Обновить `.gitignore`

```gitignore
/vendor/
/data/*.db
/data/backups/*.db
/.env
```

### 7. Обновить пути в файлах

После перемещения файлов нужно обновить `require` пути:

**В `tests/` файлах:**
```php
// Было:
$rootDir = __DIR__;
require $rootDir . '/vendor/autoload.php';
require $rootDir . '/env_helper.php';
$config = require $rootDir . '/config/avito.php';

// Стало (остается тем же — __DIR__ всегда указывает на текущий файл)
// Ничего менять не нужно!
```

**В `scripts/` файлах:**
```php
// Тоже остается тем же — __DIR__ решает проблему путей
```

> **Важно:** Все скрипты используют `$rootDir = __DIR__` для определения корня проекта, поэтому require-пути к `vendor/autoload.php`, `config/avito.php`, `env_helper.php` **не нужно менять** — они работают корректно из любой подпапки.

## Порядок выполнения

1. Создать папки `tests/`, `scripts/`, `data/backups/`
2. Переместить `collect_1000_stats.php` в `bin/`
3. Переместить тестовые файлы в `tests/`
4. Переместить диагностические скрипты в `scripts/`
5. Переместить бэкапы в `data/backups/`
6. Удалить `avito_test_temp.db`
7. Обновить `.gitignore`
8. Проверить что всё работает

## Примечания

- `collect_1000_stats.php` переносится в `bin/` как production CLI-скрипт
- Файлы используют `$rootDir = __DIR__` для определения корня, поэтому require-пути не меняются при перемещении в подпапки.
- `env_helper.php` оставляем в корне — это небольшой хелпер, используемый многими файлами.
