# План: Реализация автовыгрузки через фиды (Avito Autoload)

## Контекст

Раньше мы пытались переопубликовывать объявления напрямую через API (`POST /core/v1/items/{id}/deactivate`), но такого эндпоинта не существует. 

**Правильный подход Avito:** объявления публикуются через **автозагрузку (autoload)** с использованием **фида** (XML/Excel файл), размещённого на внешнем HTTP-URL.

### Ключевые эндпоинты из Swagger (9):

1. **`GET /autoload/v2/profile`** — получить профиль автозагрузки (feed_url, schedule, autoload_enabled)
2. **`POST /autoload/v2/profile`** — создать/обновить профиль (установить feed_url, расписание)
3. **`POST /autoload/v1/upload`** — запустить немедленную выгрузку из фидa
4. **`GET /autoload/v4/uploads`** — история загрузок
5. **`GET /autoload/v4/uploads/current`** — текущая загрузка
6. **`GET /autoload/v4/uploads/current/items`** — объявления текущей загрузки
7. **`GET /autoload/v4/uploads/last_successful`** — последняя успешная загрузка

## Этапы реализации

### Этап 1: Генератор фида (XML)

**Файл:** `src/Services/FeedGenerator.php`

**Задачи:**
- Генерировать XML-фид по формату Avito Autoload
- Поддерживать категории (динамически получать поля через `/autoload/v1/user-docs/node/{slug}/fields`)
- Формировать корректную структуру XML согласно [документации Avito](https://autoload.avito.ru/format/)

**Структура XML (базовая):**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<offer>
    <id>6304</id>
    <available>true</available>
    <price>50000</price>
    <title>Двигатель Kia Venga G4FA в наличии</title>
    <description>Полное описание...</description>
    <delivery>true</delivery>
    <contact>
        <phone>+79991234567</phone>
    </contact>
    <!-- Динамические поля категории -->
    <Brand>Kia</Brand>
    <Model>Venga</Model>
</offer>
```

**Методы:**
- `generateXML(array $ads): string` — генерация XML для списка объявлений
- `getCategoryFields(string $categorySlug): array` — получение полей категории через API
- `formatAdForFeed(array $ad, array $categoryFields): array` — маппинг DB → XML fields

### Этап 2: HTTP-сервер для фидa

**Файл:** `src/Services/FeedServer.php`

**Задачи:**
- Поднять встроенный PHP-сервер или endpoint для отдачи фида по URL
- Фид должен генерироваться динамически или сохраняться в файл в облаке
- URL фида будет настроен в профиле Avito autoload

**Варианты размещения:**
1. **Локальный сервер** — `php -S localhost:8080` для тестов
2. **Файл в облаке** — загрузка на S3/HTTP-сервер с публичным URL
3. **Endpoint в Slim** — `/feed.xml` в текущем приложении

### Этап 3: Управление профилем autoload

**Файл:** `src/Services/AutoloadProfileService.php`

**Задачи:**
- Настроить профиль autoload через `POST /autoload/v2/profile`
- Установить `feed_url` — URL где лежит фид
- Настроить `schedule` — расписание выгрузок
- Включить/выключить `autoload_enabled`

**Методы:**
- `getProfile(): array` — получить текущий профиль
- `createOrUpdateProfile(string $feedUrl, array $schedule): bool` — настроить профиль
- `enableAutoload(): bool` — включить autoload
- `disableAutoload(): bool` — выключить autoload

### Этап 4: Запуск выгрузки

**Файл:** `src/Services/AutoloadTriggerService.php`

**Задачи:**
- Запустить немедленную выгрузку через `POST /autoload/v1/upload`
- Отслеживать статус загрузки через `/autoload/v4/uploads/*`

**Методы:**
- `triggerUpload(): array` — запустить выгрузку
- `getUploadHistory(): array` — история загрузок
- `getCurrentUpload(): array` — текущая загрузка
- `getLastSuccessfulUpload(): array` — последняя успешная
- `getUploadItems(string $uploadId): array` — объявления в загрузке

### Этап 5: Интеграция с существующей системой

**Файл:** `src/Services/RepublisherService.php` (модификация)

**Задачи:**
- Удалить логику прямой деактивации (`deactivateItem`)
- Вместо этого: обновлять фид и триггерить autoload
- Синхронизировать статусы из autoload-отчётов

**Новый пайплайн:**
1. Собрать объявления для публикации
2. Сгенерировать XML-фид
3. Загрузить фид на HTTP-сервер/облако
4. Настроить профиль autoload (если нужно)
5. Запустить выгрузку `POST /autoload/v1/upload`
6. Проверить статус через `/autoload/v4/uploads/current`
7. Сохранить результаты в БД

### Этап 6: CLI команды

**Файл:** `index.php` (добавление команд)

**Новые команды:**
```bash

php index.php generate-feed

# Настроить профиль autoload
php index.php configure-feed <feed_url>

# Запустить немедленную выгрузку

# Проверить статус загрузки

# Показать историю загрузок
```

## Формат XML фида

Формат определяется категорией. Базовая структура:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<data>
    <offer id="6304">
        <price>50000</price>
        <available>true</available>
        <title>Название</title>
        <description>Описание</description>
        <picture>https://example.com/photo.jpg</picture>
        <delivery>true</delivery>
        <contact>
            <phone>+79991234567</phone>
            <name>Иван</name>
        </contact>
        <!-- Динамические поля из категории -->
        <Brand>Kia</Brand>
        <Condition>new</Condition>
    </offer>
</data>
```

Динамические поля получаются через:
```
GET /autoload/v1/user-docs/node/{category_slug}/fields
```

## Расписание выгрузок (schedule)

```json
{
    "schedule": [
        {
            "rate": 100,
            "time_slots": [0, 6, 12, 18],
            "weekdays": [0, 1, 2, 3, 4, 5, 6]
        }
    ]
}
```

- `rate` — сколько объявлений за период
- `time_slots` — часовые промежутки (по Москве)
- `weekdays` — дни недели (0=понедельник, 6=воскресенье)
