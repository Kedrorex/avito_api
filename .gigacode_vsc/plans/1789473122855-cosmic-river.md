# План: Настраиваемый анализ просмотров и приоритетный фид

## Контекст

Текущая система Avito Republisher уже умеет:
- Загружать все объявления из кабинета Avito (все статусы)
- Сохранять в SQLite БД с секционированием
- Собирать статистику (views, contacts, favorites и т.д.)
- Находить объявления-кандидаты с 0 контактов
- Переопубликовывать кандидаты (деактивация + создание нового поколения)
- Генерировать TSV фид для Avito AutoLoad

**Что нужно добавить:**
1. Настраиваемые пороги для анализа (дни + порог просмотров/контактов)
2. Приоритетный фид (кандидаты на переопубликовку первыми)

## Изменение 1: Конфигурация настраиваемых порогов

**Файл:** `config/avito.php`

Добавить раздел `analysis_thresholds` в конфигурацию:

```php
'analysis_thresholds' => [
    [
        'name' => 'zero_contacts',
        'days' => 5,
        'max_views' => 0,
        'max_contacts' => 0,
        'max_favorites' => 0,
    ],
    [
        'name' => 'low_views',
        'days' => 10,
        'max_views' => 1,
        'max_contacts' => 0,
        'max_favorites' => 0,
    ],
],
```

Каждое правило содержит:
- `name` — имя правила (для логи)
- `days` — окно анализа в днях
- `max_views` — макс. просмотров за окно (>= значит не кандидат)
- `max_contacts` — макс. контактов за окно
- `max_favorites` — макс. избранных за окно

## Изменение 3: Сервис анализа

**Новый файл:** `src/Services/AnalysisService.php`

```php
namespace App\Services;

class AnalysisService
{
    private ItemRepository $repository;
    private array $rules;
    
    public function __construct(ItemRepository $repository, array $config);
    
    /**
     * Проверить объявление на соответствие правилам.
     * Объявление — кандидат если ПОПАДАЕТ хотя бы в одно правило.
     *
     * @return array{
     *     is_candidate: bool,
     *     matched_rules: string[],
     *     total_views: int,
     *     total_contacts: int,
     *     total_favorites: int,
     *     stats_days: int
     * }
     */
    public function analyze(array $ad): array;
    
    /**
     * Найти все объявления-кандидаты.
     *
     * @return list<array{ad: array, analysis: array}>
     */
    public function findAllCandidates(): array;
}
```

**Логика `analyze()`:**
1. Получить статистику объявления из БД
2. Для каждого правила:
   - Взять последние N дней статистики
   - Просуммировать views, contacts, favorites
   - Если все три метрики <= порогов правила — правило совпало
3. Если совпало хотя бы одно правило — объявление кандидат
4. Вернуть результат с перечнем совпавших правил

**Логика `findAllCandidates()`:**
1. Получить все активные объявления
2. Для каждого вызвать `analyze()`
3. Вернуть список кандидатов с метаданными анализа

## Изменение 6: Приоритетный фид

**Файл:** `src/Services/FeedGeneratorService.php`

Изменить метод `generate()`:

```php
public function generate(bool $priorityMode = true): array
{
    $activeAds = $this->repository->getActive();
    
    if ($priorityMode) {
        // Получаем кандидатов
        $analysis = new AnalysisService($this->repository, $this->config);
        $candidates = $analysis->findAllCandidates();
        
        // Создаём мапу avito_id -> analysis
        $candidateMap = [];
        foreach ($candidates as $c) {
            $avitoId = (string)($c['ad']['avito_id'] ?? '');
            if ($avitoId !== '') {
                $candidateMap[$avitoId] = $c;
            }
        }
        
        // Разделяем на кандидатов и обычных
        $candidateAds = [];
        $normalAds = [];
        foreach ($activeAds as $ad) {
            $avitoId = (string)($ad['avito_id'] ?? '');
            if (isset($candidateMap[$avitoId])) {
                $candidateAds[] = [
                    'ad' => $ad,
                    'analysis' => $candidateMap[$avitoId]['analysis'],
                ];
            } else {
                $normalAds[] = ['ad' => $ad, 'analysis' => null];
            }
        }
        
        // Кандидаты первыми, затем обычные
        $ordered = array_merge($candidateAds, $normalAds);
    } else {
        $ordered = array_map(fn($ad) => ['ad' => $ad, 'analysis' => null], $activeAds);
    }
    
    // Записываем в TSV
    foreach ($ordered as $item) {
        $row = $this->buildRow($item['ad'], $item['analysis']);
        if ($row !== null) {
            fputcsv($handle, $row, "\t");
            $count++;
        }
    }
}
```

Также обновить `buildRow()` для поддержки анализа:
- Добавлять колонку "Приоритет" (Кандидат на переопубликовку / Обычное)
- Добавлять колонку "Правила" (имена совпавших правил)
