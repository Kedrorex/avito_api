# План: Создание инструкции по запуску `index.php`

## Цель
Создать подробную инструкцию по запуску `index.php` со списком всех CLI-команд, их описанием, аргументами и примерами использования.

## Что нужно сделать

### 1. Изучить текущее состояние
- Файл `README.md` уже содержит часть информации (команды `collect-stats` и `ad`)
- `index.php` содержит 11 CLI-команд, описанных в `switch`
- `AvitoController.php` содержит реализации всех методов

### 2. Создать инструкцию в README.md
Добавить в `README.md` секцию «CLI-команды» со следующим содержанием:

#### Структура файла:
1. **Заголовок** — что это за файл
2. **Быстрый старт** — подготовка (composer install, .env, запуск)
3. **Полный список команд** — таблица или секции для каждой команды:
   - `run` — полный пайплайн (синхронизация → статистика → кандидаты → републикация)
   - `sync` — синхронизация с Avito API
   - `active` — список активных объявлений
   - `status-counts` — подсчёт по статусам
   - `republish <id>` — републикация конкретного объявления
   - `stats [from] [to]` — получение статистики за период
   - `collect-stats [days]` — сбор статистики в SQLite (1–270 дней)
   - `ad <id>` — просмотр сохранённого объявления со статистикой
   - `item <id>` — детальная информация об элементе из API
   - `collect-candidates [days]` — сбор кандидатов на републикацию
   - `show-candidates` — вывод списка кандидатов
4. **HTTP-режим** — как запустить веб-сервер и список эндпоинтов
5. **Важные замечания** — лимиты API, паузы, база данных
